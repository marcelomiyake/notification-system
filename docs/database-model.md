# Notification System database model

This is the human-readable model of the repository-owned PostgreSQL schema. The migration is authoritative; update this inventory when the migration changes.

- **Owner:** `notification-system`, database migrations under [`database/migrations/`](../database/migrations/).
- **Known application consumers:** `notification-system` / `notification-api` and `notification-system` / `notification-worker`. No cross-repository database consumer is identified.
- **Database:** PostgreSQL; tables are in the default `public` schema.
- **Source:** [`0001_notification_system.sql`](../database/migrations/0001_notification_system.sql).

## Tables

### `api_callers`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key | Stable caller identifier. |
| `name` | TEXT, required | Human-readable caller name. |
| `api_key_sha256` | TEXT, required, unique | SHA-256 digest used to authenticate the caller; the raw key is not stored. |
| `enabled` | BOOLEAN, required, default `TRUE` | Whether the caller may submit notifications. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Record creation time. |

### `recipients`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key | Stable recipient identifier. |
| `display_name` | TEXT, required | Name shown to operators. |
| `email` | TEXT, nullable | Email delivery destination. |
| `phone_number` | TEXT, nullable | SMS delivery destination. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Record creation time. |
| `updated_at` | TIMESTAMPTZ, required, default `now()` | Most recent recipient update time. |

### `devices`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key, generated by `gen_random_uuid()` | Device registration identifier. |
| `recipient_id` | UUID, required, FK to `recipients.id`, cascade delete | Device owner. |
| `platform` | TEXT, required, `ios` or `android` | Push platform. |
| `device_token` | TEXT, required | Provider device token. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Registration time. |
| `last_logged_in_at` | TIMESTAMPTZ, required, default `now()` | Most recent device login time. |
| `(platform, device_token)` | Unique constraint | Prevents duplicate platform registrations. |

### `preferences`

| Column | Type and rules | Description |
| --- | --- | --- |
| `recipient_id` | UUID, required, FK to `recipients.id`, cascade delete | Preference owner. |
| `channel` | TEXT, required; `ios_push`, `android_push`, `sms`, or `email` | Delivery channel governed by this preference. |
| `opt_in` | BOOLEAN, required, default `FALSE` | Whether the recipient permits delivery through this channel. |
| `updated_at` | TIMESTAMPTZ, required, default `now()` | Preference update time. |
| `(recipient_id, channel)` | Composite primary key | One preference per recipient and channel. |

### `templates`

| Column | Type and rules | Description |
| --- | --- | --- |
| `template_id` | UUID, required | Stable logical template identifier. |
| `version` | INTEGER, required, greater than zero | Immutable version number. |
| `name` | TEXT, required | Display name for the template. |
| `channel` | TEXT, required; supported notification channel | Channel for which the template is rendered. |
| `subject` | TEXT, required, default empty | Email or push subject. |
| `body` | TEXT, required | Template body with supported placeholders. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Version creation time. |
| `(template_id, version)` | Composite primary key | Identifies one immutable template version. |

### `notifications`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key | Stable notification identifier. |
| `caller_id` | UUID, required, FK to `api_callers.id` | Authenticated submitter. |
| `recipient_id` | UUID, required, FK to `recipients.id` | Intended recipient. |
| `channel` | TEXT, required; supported notification channel | Delivery channel selected for this notification. |
| `status` | TEXT, required; `accepted`, `scheduled`, `queued`, `processing`, `retrying`, `sent`, `suppressed`, or `failed` | Current notification lifecycle state. |
| `scheduled_at` | TIMESTAMPTZ, nullable | Requested scheduled delivery time. |
| `template_id` | UUID, nullable | Referenced template identifier. |
| `template_version` | INTEGER, nullable | Referenced template version. |
| `(template_id, template_version)` | Composite FK to `templates` | Ensures a referenced template version exists. |
| `payload` | JSONB, required | Data used to render or deliver the notification. |
| `attempts` | INTEGER, required, default `0` | Number of provider attempts recorded. |
| `last_error` | TEXT, nullable | Most recent delivery error. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Acceptance time. |
| `updated_at` | TIMESTAMPTZ, required, default `now()` | Last state change time. |

### `idempotency_keys`

| Column | Type and rules | Description |
| --- | --- | --- |
| `caller_id` | UUID, required, FK to `api_callers.id` | Scope of the idempotency key. |
| `idempotency_key` | TEXT, required, 1–128 characters | Client-provided request key. |
| `payload_sha256` | TEXT, required | Digest used to detect reuse with a different request body. |
| `notification_id` | UUID, required, FK to `notifications.id` | Notification created by the original request. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Key registration time. |
| `(caller_id, idempotency_key)` | Composite primary key | Enforces key uniqueness per caller. |

### `outbox`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key, generated by `gen_random_uuid()` | Durable dispatch record identifier. |
| `notification_id` | UUID, required, FK to `notifications.id`, cascade delete | Notification to dispatch. |
| `dispatch_number` | INTEGER, required, greater than zero | Dispatch sequence for this notification. |
| `channel` | TEXT, required; supported notification channel | Queue destination. |
| `available_at` | TIMESTAMPTZ, required, default `now()` | Earliest time a publisher may send the message. |
| `published_at` | TIMESTAMPTZ, nullable | Time the outbox event was published. |
| `leased_until` | TIMESTAMPTZ, nullable | Publisher lease expiry. |
| `publish_attempts` | INTEGER, required, default `0` | Number of broker publish attempts. |
| `last_error` | TEXT, nullable | Most recent publish failure. |
| `created_at` | TIMESTAMPTZ, required, default `now()` | Outbox record creation time. |
| `(notification_id, dispatch_number)` | Unique constraint | Prevents duplicate dispatch sequence entries. |

### `delivery_attempts`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key, generated by `gen_random_uuid()` | Attempt record identifier. |
| `notification_id` | UUID, required, FK to `notifications.id`, cascade delete | Notification being delivered. |
| `attempt_number` | INTEGER, required, greater than zero | Attempt sequence. |
| `outcome` | TEXT, required; `started`, `accepted`, `transient_error`, `permanent_error`, or `suppressed` | Result of the provider attempt. |
| `error_code` | TEXT, nullable | Provider or adapter error code. |
| `started_at` | TIMESTAMPTZ, required, default `now()` | Attempt start time. |
| `completed_at` | TIMESTAMPTZ, nullable | Attempt completion time. |
| `(notification_id, attempt_number)` | Unique constraint | Prevents duplicate attempt numbers. |

### `recorded_deliveries`

| Column | Type and rules | Description |
| --- | --- | --- |
| `id` | UUID, primary key, generated by `gen_random_uuid()` | Recorded adapter acceptance identifier. |
| `notification_id` | UUID, required, unique, FK to `notifications.id`, cascade delete | Notification accepted by the local adapter. |
| `channel` | TEXT, required; supported notification channel | Channel used. |
| `masked_destination` | TEXT, required | Redacted destination displayed to operators. |
| `rendered_subject` | TEXT, required, default empty | Rendered subject. |
| `rendered_body` | TEXT, required | Rendered message body. |
| `accepted_at` | TIMESTAMPTZ, required, default `now()` | Local adapter acceptance time; not proof of final provider delivery. |
